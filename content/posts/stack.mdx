This site is built with **Astro**, a static site generator that compiles pages with Vite and can hydrate individual pieces of a page as [islands](https://docs.astro.build/en/concepts/islands/). That keeps a mostly static site fast while still leaving room for a little interactivity. I am hosting with [Cloudflare Pages](https://pages.cloudflare.com/).

### Highlighted technologies

| Area | Tools |
| --- | --- |
| **Low-level & systems** | C, C++, WebAssembly, Make, Bash, Lua |
| **Data & ML runtimes** | Python, R, Jupyter, PyTorch, Lightning, Pandas, SQL |
| **Networking & infrastructure** | Docker, systemd, Cloudflare, GitHub, AWS, Tailscale/WireGuard |
| **Graphics & visualization** | MapLibre GL, Three.js, D3.js, plotting libraries, Retool |
